# chatbot

ExpertHelp front end built with React (Vite) and Tailwind CSS. It is a static site: no backend or database.

Pages: Home (`/`), Printers & Scanners (`/category/printers`), Contact Support (`/contact`),
Privacy Policy (`/privacy`) and Terms of Service (`/terms`).

## Run

```bash
npm install
npm run dev
```

Open http://127.0.0.1:5173

## Build

```bash
npm run build
```

## Images

The photos from the original design only load for people logged into Stitch, so every image falls back to a
stand-in file in `public/images` (see the README there). Replace those files with real photos before publishing.
